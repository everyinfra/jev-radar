What is Jev?Jev 是什么

Jev is TypeSafe AI's first System One model (released 2026-09-15). It never writes prose: you send state plus typed questions and get decisions your code can branch on — Noul (is this true?), Choice (which option fits?) and Score (how good, on your rubric?). Jev 是 TypeSafe AI 的第一个 System One 模型（2026-09-15 发布）。它不写句子：你给它状态和带类型的问题，它直接返回代码能分支的判断——Noul（是不是真的）、Choice（选哪个）、Score（按你的标准打几分）。
A We inspected the artifact: read the repo, hit the live demo or called the API ourselves. A 我们亲自核验过：读了仓库、打开了在线演示，或自己调过接口。

B A primary source is on record (repo or original post), inspected at description level. B 有一手来源在案（仓库或原帖），核到描述层面。
